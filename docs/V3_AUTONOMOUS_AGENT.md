# V3 全自动 AI 虚拟盘

V3 与 V1/V2 完全隔离。V1 `state/`、V2 `shadow_state/v2/` 和历史账本均不得改写。

## 运行原则

- 交易范围仅限沪深 A 股主板，排除创业板、科创板、北交所、B 股、ST 和退市整理股票。
- A/B/C/D/L 各自以 1,000,000 元虚拟资金独立起跑。
- ChatGPT 每个交易日读取完整市场简报、持仓和当日公开信息，直接给出五个组合的目标仓位。
- 代码不再使用层层叠加的选股阈值替 ChatGPT 决策。代码只执行真实交易约束和数据完整性检查。
- 不需要用户审批；这是纯虚拟盘，任何模块都不得连接银河证券或其他真实券商。

## GitHub 不再决定是否成交

每份决策同时锁定 `decision_date` 和 `execute_on`。系统晚运行时仍使用 `execute_on` 当天的真实开盘价、滑点和费用补记，不能因 GitHub Actions 延迟而把订单作废，也不能改用稍后的价格。

GitHub 负责代码、审计和网页镜像。ChatGPT 定时任务负责唤醒、分析、写入决策和失败重试。若 GitHub 暂时不可用，任务必须在同一聊天保留完整恢复载荷，下次运行先恢复旧决策再生成新决策。

每份 AI 决策只能引用同日 `agent_state/v3/briefs/` 中实际存在的候选代码；下一次执行会重新读取该简报验证，禁止模型编造或绕过股票池。

## 不可伪装成成功

- 行情不完整：整批不成交，保留待恢复状态。
- 决策格式错误或包含非主板代码：整批拒绝。
- 五本账本不能一起推进：全部不写入。
- 只有审计事件、五本账本和公开汇总一致，才算本次运行成功。
